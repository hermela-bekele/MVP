### Module Overview:
Relations describe connections between elements of sets using ordered pairs, tables, graphs, or mapping diagrams. A function is a special relation where each input has exactly one output. Inequalities represent regions of solutions on a plane, while function composition models multi-step processes by combining functions in sequence.

## 📖 Four Comprehensive Sessions

### Session 2.1: The Concept of Relation (1.5 hours)
**Learning Objectives:**
- Explain a relation as a connection between two sets
- Represent relations using ordered pairs, tables, mapping diagrams, and graphs
- Identify domain and range

**Key Teaching Points:**
- Relations are sets of ordered pairs $(x, y)$
- Relations can be one-to-one, one-to-many, or many-to-one
- Domain = all inputs, Range = all outputs
- Same relation can be shown in multiple forms
- Real-life connections (students-subjects, cities-climate, products-prices)

**Classroom Activity:**
Real Ethiopian crop-region pairing data with hands-on mapping diagram creation

---

### Session 2.2: Relations Involving Inequalities (1.5 hours)
**Learning Objectives:**
- Graph linear inequalities
- Identify solution regions
- Interpret domain and range from graphs

**Key Teaching Points:**
- Inequalities represent infinite solution sets
- Solid line (≤, ≥) vs dashed line (<, >)
- Test point method for determining correct region
- Overlapping regions for multiple inequalities
- Real-world modeling (constraints, limits, budget)

**Classroom Activity:**
Graph $y < 2x + 1$ and $y \geq x$, identify overlapping solution regions

---

### Session 2.3: The Concept of Function (1.5 hours)
**Learning Objectives:**
- Distinguish functions from general relations
- Represent functions in multiple forms
- Apply the vertical line test
- Find inputs and outputs

**Key Teaching Points:**
- Functions assign exactly ONE output per input
- Many-to-one allowed, one-to-many NOT allowed
- Vertical line test for visual identification
- Multiple representations (equations, tables, graphs, mapping)
- Reverse operations for finding inputs from outputs

**Classroom Activity:**
Function machine pattern recognition ($-2 \rightarrow -6$, $2 \rightarrow 6$, $4 \rightarrow 12$)

---

### Session 2.4: Composition of Functions (1.5 hours)
**Learning Objectives:**
- Evaluate composite functions
- Interpret function composition in real-world contexts
- Understand order of operations in functions

**Key Teaching Points:**
- Composition means applying functions in sequence
- **Order matters:** $f(g(x)) \neq g(f(x))$
- Inner function evaluated first
- Models multi-step real-life processes
- Domain depends on both functions combined

**Classroom Activity:**
Production-profit scenario with $f(t) = 5t$ and $g(n) = 20n - 50$
